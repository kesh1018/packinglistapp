# Packing Pal

Android packing-list app: React + TypeScript + Tailwind (EasyUI components) in a Capacitor 8 shell.
App logic (recommendations, weather, reminders, sharing) lives in `src/lib/`; `android/` is the
Capacitor-generated native project (Java, no Kotlin).

## Toolchain
- Node 20+ and npm
- JDK 21 for Gradle: `export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home`
- Android SDK at `/opt/homebrew/share/android-commandlinetools` (platform 36, build-tools 36), set in `android/local.properties`

## Commands
Web (run from the repo root):
- `npm run dev`: dev server on http://localhost:5199
- `npm run typecheck`: TypeScript project build check
- `npm run lint`: ESLint
- `npm test`: Vitest unit tests (`src/lib/__tests__/`)
- `npm run check`: typecheck + lint + tests
- `npm run build`: production web bundle in `dist/`

Android (run from `android/` after `npm run build && npx cap sync android`):
- `./gradlew lintRelease`
- `./gradlew testReleaseUnitTest`
- `./gradlew connectedAndroidTest`: needs a running emulator or device. **It uninstalls the app when it finishes, which wipes its saved trips.** Back up `shared_prefs/CapacitorStorage.xml` first (`adb shell run-as com.uptima.packingpal cat shared_prefs/CapacitorStorage.xml`) if the device holds data you care about
- `./gradlew bundleRelease assembleRelease`: R8-minified release build; signed only when `android/keystore.properties` or the `PACKINGPAL_*` env vars are set (see `android/keystore.properties.example`)
- R8 mapping file: `android/app/build/outputs/mapping/release/mapping.txt`

## Rules
- **Before saying a task is done, run `npm run check`; if you touched anything under `android/` or
  native config, also run `npm run build && npx cap sync android` and
  `./gradlew lintRelease testReleaseUnitTest assembleRelease`. Fix every failure first.**
- Never print, move or commit the keystore, `keystore.properties` or signing passwords.
- `android/` is generated by Capacitor but has hand edits: release signing, R8, locale filter and
  LeakCanary in `app/build.gradle`; StrictMode in `MainActivity.java`; `SCHEDULE_EXACT_ALARM`
  removed in `AndroidManifest.xml`. Keep these if you regenerate the platform.
- Add R8 keep rules only when a release build breaks, and keep them as narrow as possible (no package-wide keeps).
- Target SDK is 36 (Android 16), which enforces edge-to-edge layout. Pad UI with the `.safe-top` / `.safe-bottom`
  classes (they read Capacitor's `--safe-area-inset-*` variables), not fixed offsets.
- Weather comes from Open-Meteo (no API key). Don't add secrets to the client bundle.
- Bump `versionCode` in `android/app/build.gradle` for every Play upload after the first.
